## 🚀 Quick Practice (Copy-Paste Ready)

```bash
# Search text in file
grep "error" logfile.txt

# Ignore case
grep -i "warning" logfile.txt

# Show line numbers
grep -n "failed" logfile.txt

# Recursive search
grep -r "TODO" /project

# Count matches
grep -c "ERROR" logfile.txt
```
